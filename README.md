# rotas.delivery
**GPS Entregador** é um GPS grátis que abre no navegador do celular, sem instalar nada. Você busca o endereço ou cola o link do cliente, adiciona várias entregas, escolhe a ordem (ou deixa o app sugerir a mais curta) e inicia a navegação com voz em português. Na chegada ele avisa o número da casa e o lado.
